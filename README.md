# Taller Algoritmos Evolutivos / Algoritmos Genéticos --- *Realizado por Antonio Parra*
Implementar, experimentar y analizar algoritmos genéticos como técnica de Inteligencia Artificial para resolver problemas.
El estudiante deberá comparar representación, función de aptitud, selección, cruzamiento, mutación y criterios de parada en diferentes problemas, diseña, explica, y despliega la solución
## Instrucciones de uso
Todas las dependencias del proyecto se encuentran definidas en *requirements.txt*, al clonar el repositorio se deben instalar dichas dependencias:
```pip install -r requirements.txt```

Este proyecto utiliza:
- Flask (Despliegue del aplicativo web)
- matplotlib (Graficacion de funciones para Spyder)

Para correr el proyecto correr el comando:
```python app.py```
el cual ejecutara el aplicativo en *localhost* en el puerto indicado en su terminal.
